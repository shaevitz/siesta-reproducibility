# Prompt records

These are the exact prompt and JSON-schema files included with the preprint source package. The historical filenames retain the internal experiment identifiers `orer` and `pletcher` so that their SHA-256 hashes remain tied to the executed records. The paper refers to the corresponding systems as the **16-fly dataset** and **10-fly dataset**.

The prompt files document the interactive Codex VLM procedure; they are not an API wrapper. Review prompts require the image packet described in `operational_packet_template.txt` and preserve the rule that temporal frames may inform the target-frame estimate but may not contribute copied, averaged or smoothed coordinates.
